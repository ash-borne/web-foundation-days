About QuickNotes

QuickNotes is a simple note-taking app for jotting down ideas, tasks and reminders. It keeps everything in one place so you can find your notes quickly.

How to use QuickNotes

  1. Open QuickNotes and click "New note".
  2. Type your title and the text of your note.
  3. Save the note so it appears in your list.
  4. Click any note in the list to read or edit it later.

Features

  • Fast note creation
  • Simple, clean layout
  • Search across all your notes
  • Keyboard shortcuts for common actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + Q Search your notes
